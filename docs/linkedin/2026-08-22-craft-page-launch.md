The New Craft — the skills I believe matter most for engineers now that writing the code is the smallest part of the job.

Working with agents makes an engineer an overnight manager — so these read like a people-leader's list:

- First principles — knowing what right looks like before I delegate
- Owning the outcome — no matter which agent wrote it
- Precise briefs — vague specs come back polished and wrong
- Harness engineering — tools, context, evals as one discipline
- Challenging confident answers before trusting them
- A tester's mindset — deciding what verified actually means
- Security as risk ownership, down to least privilege
- Re-baselining what models can and can't do, every few months

The full essay — the why behind each — is on my site. My read, not a rulebook; if yours differs, I'd like to hear it.
