The design router, verified

25 design-domain skills are installed on this machine. One owned router decides which single one loads for any design, UI, or motion request — and this session put every claim it makes under adversarial verification, settled its one untested assumption, and fixed what that turned up.

Verdict: the design is sound, consistent end to end, and now fully live — the nudge hook was registered (user-authorized) at the end of this session and fires from the next session on. Remaining: the acceptance gate — PR #26 is open.

How it works

One request path, two entry lanes

Only a skill's description sits in model context — the body loads after it fires. So triggering lives in one owned place: the design-router skill carries every trigger phrase, and its body is a dispatch table with zero design opinions. The skills it routes to are symlinked third-party content, never edited.

Refactor split

"Refactor" routes on what the change is for, never the file extension. State refactor in a .tsx → logic lane. Spacing change in a .ts markup builder → design lane. Both present → split, logic first.

Stack gate

design-taste-frontend / high-end-visual-design need React and Tailwind in the actually-read package.json. Foundry fails it on purpose — React there is one scoped component, no Tailwind.

Exclusion sets

Never two from one set: the three full rulebooks (impeccable ⊗ taste ⊗ high-end); brainstorming ⊗ impeccable; emil ⊗ review-animations. One rulebook per request, always.

Out of the pool new

Native (SwiftUI/UIKit) → swiftui-expert-skill / apple-design / ecc:liquid-glass-design directly. The ecc design fleet stays unrouted — overlapping or React-locked. Now written down as a decision, not an accident.

The two "call by name" skills can never be model-called

Skill(pick-ui-library) was invoked for real: hard error — the disable-model-invocation flag blocks every model Skill() call, not just auto-firing. The router's "call them by name" and the /design <name> fallback were both mechanically impossible. Fix shipped in four files: the working path is you typing /<skill-name>, and /design <name> now reads the skill file from disk instead. Probe 9 of the acceptance gate now tests the handoff, not the settled mechanism.
